# Dotfiles

## Commits

- A commit message is one random emoji and nothing else, e.g. `🧀`.
- Before every commit, check the staged changes for secrets: tokens, API keys, passwords, private keys, OAuth
  credentials, session cookies, `.env` contents. Personal info at the level already in the repo (names, email,
  hostnames, paths) is fine. If something sensitive is staged, leave it out and say so.
