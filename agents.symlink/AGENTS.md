# Global instructions

## Machine-local instructions

If `~/.agents/AGENTS.local.md` exists, read it before starting work.
It contains machine-specific additions and overrides to these global
instructions. If absent, continue normally.

## Posting on the user's behalf

When posting anything public under the user's account (GitHub reviews, PR/issue comments,
Discord/Slack messages, emails), start the text with "(Agent) " so readers know an agent wrote it.
