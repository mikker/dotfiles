1 · Menu bar USER

Persistent top-level shell chrome. Hosts widgets; it is not a popup.

mikker.bar · omarchy/plugins/mikker.bar/Bar.qml

2 · Tooltip USER

Small hover label owned by the custom bar.

mikker.bar · omarchy/plugins/mikker.bar/Bar.qml

3 · Media panel SYSTEM

MPRIS now-playing card opened from the media bar widget. Available, but not currently in the bar layout.

omarchy.media · /usr/share/omarchy/shell/plugins/services/media/BarWidget.qml

4 · Audio panel SYSTEM

The output/input device panel opened from the VOL icon. This is the audio-specific target for tighter vertical and wider horizontal insets.

omarchy.audio · /usr/share/omarchy/shell/plugins/panels/audio/Panel.qml

5 · Volume/media OSD USER

Transient centered feedback triggered by volume and playback keys—not the Audio panel.

mikker.osd · omarchy/plugins/mikker.osd/Osd.qml

6 · Notification USER

Desktop notification card, separately sized and positioned.

mikker.notifications · omarchy/plugins/mikker.notifications/components/NotificationCard.qml
